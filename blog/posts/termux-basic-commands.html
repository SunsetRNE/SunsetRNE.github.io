Termux 从零开始（二：常用指令大白话入门 ​

上一篇讲了下载安装和手机操作，还没装好的先看 （一）下载、安装与手机基本操作。

本篇只讲一件事：最常用的指令，每条都用人话解释。不用背，用多了自然记住；记不住就回来查。

认路三兄弟：pwd /ls/cd ​

终端和手机文件管理器最大的区别：没有 "界面"，全靠命令问 "我在哪、有什么、去哪个文件夹"。

sh
pwd        # 打印当前目录 = 问"我现在在哪"
ls         # 列出当前目录的文件 = 问"这里有什么"
ls -la     # 列出全部文件（包括隐藏的），带详细信息。最常用的 ls 写法
cd 文件夹名   # 进入某个文件夹（cd = change directory）
cd ..      # 返回上一级
cd ~       # 回到"家"（打开 Termux 时的默认位置）
cd -       # 回到上一个待过的目录（两个目录间来回切换的神器）

几个必须记住的规则：

  • 路径：从 / 开始的是绝对路径（cd /sdcard，直接写名字的是相对路径（cd 下载）
  • .. 是上一级，~ 是家，. 是当前目录（后面会用到）
  • 输入文件夹名时按 Tab 键可以自动补全，不用打全
  • 找不到文件时先 pwd 看自己在哪，再 ls 看有什么，一步一步 cd 过去

建文件 / 改文件 / 删文件 ​

sh
mkdir 名字        # 新建文件夹（make directory）
touch 文件名      # 新建一个空文件
nano 文件名       # 用最简单的编辑器打开文件（新手首选，vim 以后再说）
cat 文件名        # 把整个文件内容打印到屏幕上（短文件用）
head -20 文件名   # 只看文件前 20 行
tail -20 文件名   # 只看文件最后 20 行（看日志排错神器）
less 文件名       # 分页查看大文件（按 q 退出）
cp 原文件 新文件   # 复制文件
mv 原位置 新位置   # 移动文件（也能当重命名用：mv 旧名 新名）
rm 文件名         # 删除文件
rm -r 文件夹名    # 删除整个文件夹（连带里面的所有东西）

⚠️ Termux 没有回收站：rm 删掉的东西找不回来。删文件夹前先 ls 看清楚里面是啥，别手滑。

nano 编辑器速成（会用这个就够写脚本了） ​

sh
nano 文件名
操作按键
保存音量减 + O（Ctrl+O，回车确认
退出音量减 + X（Ctrl+X）
没保存就退出时会问按 y 保存，n 不保存，回车确定

在 nano 里按 音量加 + Q 能呼出 / 隐藏额外按键行，里面有现成的 Ctrl 键可以点。

装软件：pkg 全家桶 ​

Termux 装软件靠 pkg（它是 apt 的友好封装，新手只用 pkg 就行：

sh
pkg update            # 更新软件列表（装软件前先跑）
pkg upgrade           # 升级所有已装软件
pkg search 关键词      # 搜索软件（比如 pkg search python 看有哪些 python 版本）
pkg install 软件名     # 安装：pkg install git python nodejs
pkg remove 软件名      # 卸载
pkg list-installed    # 查看已安装的软件

装完就能用，比如：

sh
pkg install git     # 装 git
git --version       # 验证：能输出版本号就是装好了

看系统状态 ​

sh
whoami      # 我是谁（显示 u0_aXXX 之类是正常的，那是安卓给 app 的用户名）
uname -a    # 系统内核信息（好奇时看看）
date        # 当前时间
df -h       # 磁盘空间还剩多少（h = 人类可读）
free -h     # 内存还剩多少
clear       # 清屏（等价于 音量减+L）
history     # 查看输入过的命令历史（按 ↑ 键也能一条条翻）

跑脚本 / 执行权限 ​

从网上下载或自己写的脚本（.sh 文件）不能直接跑，要先给 "执行权限"：

sh
chmod +x 脚本名.sh    # 给脚本加执行权限
./脚本名.sh           # 运行它（前面那个 ./ 不能省，表示"当前目录下的"）

卡住了怎么办：错误速查表 ​

你看到的人话解释怎么办
command not found没装这个软件pkg install 对应软件（比如提示 git 就装 git）
Permission denied没有执行权限chmod +x 文件 再跑
命令卡住不动程序在跑 / 在等你输入音量减 + C 中断
输出刷屏内容太多重跑时在末尾加 | head 只看开头
No such file or directory路径写错了pwd 看在哪，ls 看有什么，cd 到正确位置
卡在 nano 出不来在编辑器里音量减 + X 退出，问保存吗按 y
Do you want to continue?装软件时问 "继续吗"输入 y 回车

小练习（照着做一遍就上手了） ​

sh
mkdir test             # 建一个 test 文件夹
cd test                # 进去
touch hello.txt        # 建一个空文件
nano hello.txt         # 打开它，写一行字，保存退出（音量减+O，音量减+X）
cat hello.txt          # 把内容打印出来，看到你写的字就成功了
cd ..                  # 回上一级
rm -r test             # 练习完删掉 test 文件夹

小结 ​

  • 认路：pwd 我在哪，ls 有什么，cd 去哪，.. 上一级，~ 家
  • 文件：mkdir 建夹、nano 编辑、cat/head/tail 查看、rm -r 删除（没有回收站）
  • 装软件：pkg update && pkg install 软件名
  • 跑脚本：chmod +x 文件 && ./文件
  • 卡住先看错误速查表，90% 的问题就是 "没装 / 没权限 / 路径不对"
