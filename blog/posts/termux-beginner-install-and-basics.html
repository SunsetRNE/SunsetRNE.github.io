Termux 从零开始（一：下载、安装与手机基本操作 ​

本系列写给完全没接触过终端的人。如果你已经在电脑上玩过终端，可以直接跳到 第二篇。

这个系列是干嘛的 ​

本站很多教程（比如克隆仓库、跑脚本、编译内核）都要在手机上打开一个 "终端" 来操作。如果你连终端是什么、去哪下载都不知道，那教程第一行命令就会把你劝退。

所以有了这个系列，一共三篇：

  1. 本篇：下载安装 + 手机上的基本操作（不用记命令）
  2. 第二篇：常用指令大白话入门：认路、建文件、装软件
  3. 第三篇：组合指令与实用套路：管道、重定向、一键操作

看完三篇，本站其他教程对你来说就不再是天书了。

Termux 是什么 ​

一句话：Termux 是安卓手机上的终端模拟器 —— 装一个 App，手机就拥有了一个类似电脑命令行（Linux 终端）的环境。

  • 不需要 root
  • 不需要电脑
  • 可以装 git、python、node 等大量软件（靠内置的 pkg 软件源）

它不是完整的 Linux 系统（那需要额外的 proot-distro，第三篇末尾会讲，但日常折腾完全够用。

第一步：下载安装（连终端都没下过？从这里开始） ​

通道一：国内直连（不想折腾网络的选这个） ​

用手机浏览器打开：

https://get.zerotermux.dev

会自动开始下载 ZeroTermux 的安装包（.apk 文件。下载完打开它，系统提示 "允许安装未知来源应用" 就点允许，然后一路下一步装完。

⚠️ 说明：ZeroTermux 是基于 Termux 的国内优化版（开源 GPL，不是 Termux 官方出品。它的好处是内置了国内软件源、对国内网络友好；介意第三方软件的话，就选下面的通道二。只从上面这个网址下载，不要从任何第三方 "软件站" 下载，那些地方可能加料。

本博客的所有命令在 ZeroTermux 和官方 Termux 上完全通用，装哪个都不影响跟教程。

通道二：官方原版（能访问 GitHub 的选这个） ​

  1. 手机浏览器打开 https://github.com/termux/termux-app/releases
  2. 找带 Latest 标记的最新稳定版（目前是 v0.118.3）—— 看到 beta / Pre-release 字样的跳过
  3. 点 Assets 展开下载列表，下载名字里带 universal 的那个 .apk 文件
  4. 打开下载好的 apk 安装，同样允许 "未知来源应用"

下载列表里可能有好几个文件：universal 是 "万能版"（拿不准就选它，arm64-v8a 是近几年的手机用的，都行。文件名里的 debug 字样是正常的，GitHub 官方发布的就是这种构建。

第二步：装完先做三件事 ​

打开 Termux，你会看到一个黑底（或深色）界面，光标在闪 —— 这就是终端了。先输入下面这条命令，回车：

sh
pkg update && pkg upgrade
  • 这是 "更新软件源 + 升级所有软件"，以后每装新软件前都建议先跑一遍
  • ZeroTermux 已经配好国内源；官方 Termux 如果提示慢或报错，先运行 termux-change-repo，在弹出的菜单里选一个国内镜像（清华 / 中科大）再重试
  • 中间会问 Do you want to continue? [Y/n]，输入 y 回车

然后解锁手机文件访问权限（想读写手机里的文件必须做：

sh
termux-setup-storage

弹窗授权后，~/storage 就是你的手机文件入口（照片、下载、音乐都在里面。

第三步：手机上的基本操作（不用记命令） ​

会话：Termux 的 "窗口" ​

一个 ** 会话（session）** 就是一个终端窗口。你可以开好几个会话，比如一个跑下载、一个编辑文件、一个随便玩。

想做什么怎么做
新开会话从屏幕左侧边缘向右滑，拉出抽屉 → 点底部 NEW SESSION
切换会话拉出抽屉点会话名；或者直接在屏幕上左右滑动切换
关闭会话在会话里输入 exit 回车；或长按抽屉里的会话名 → 关闭
重命名会话长按抽屉里的会话名 → Rename（方便区分 "下载中"" 写代码 "）

复制 / 粘贴 ​

手机上没法 Ctrl+C / Ctrl+V（终端里也不行：长按屏幕会弹出菜单，里面有 Copy / Paste。复制先长按选中文字，粘贴长按选 Paste。

最关键的一个知识：音量键 = 键盘修饰键 ​

终端里到处要用 Ctrl（中断程序、清屏、ESC（退出编辑器、Tab（自动补全，但手机键盘没有这些键。Termux 的解决办法：

按键相当于常见用途
音量减 + XCtrl + X中断卡住的程序（音量减 + C、清屏（音量减 + L）
音量加 + EESC退出 vi/vim 编辑器
音量加 + TTab自动补全
长按音量减特殊字符表呼出 | & ; 等符号

额外按键行（强烈建议打开） ​

从左侧滑出抽屉 → 长按左下角的 KEYBOARD 图标（或按 音量加 + Q。屏幕键盘上方会多出一排 ESC / CTRL / TAB / ALT / - / | / 虚拟键，点一下就是那个键，比记音量键组合舒服多了。

第一个小练习 ​

在终端里依次输入（每行输入完按回车：

sh
pwd        # 我在哪？（会显示一长串路径，这就是你的"家"）
ls         # 这里有什么？（现在应该是空的）
whoami     # 我是谁？（显示 u0_aXXX 之类的，正常）
echo "你好，Termux"   # 打印一句话

看到输出，说明你的终端已经能正常干活了。

小结 ​

  • 下载：国内选 ZeroTermux（get.zerotermux.dev，能翻墙选官方（GitHub Releases，选 universal 的 apk）
  • 装完先跑 pkg update && pkg upgrade，再 termux-setup-storage
  • 会话靠左侧抽屉管理；复制粘贴长按屏幕；音量减 = Ctrl、音量加 = ESC
  • 建议打开额外按键行
