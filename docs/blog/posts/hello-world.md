## 为什么用 Markdown 写博客？

- 纯文本，Git 友好，可以追溯每一次修改
- 代码块高亮、表格、图表开箱即用
- 写完后 push 到 GitHub，自动构建上线，零运维

## 代码块示例

```js
const greeting = (name) => `Hello, ${name}!`;
console.log(greeting("World"));
```
